## 1. 项目概述

| 项 | 内容 |
|---|---|
| 定位 | 复刻原作**全部核心玩法**的 Web 端 RTS Demo，之后在其上扩展 |
| 技术栈 | Vite 6 + TypeScript 5.6 + PixiJS 8 |
| 架构原则 | **模拟层 / 渲染层严格分离**。`map / pathfinding / entities / game / ai` 零渲染依赖，可直接迁移 Godot（C#） |
| 模拟方式 | 固定步长 30Hz（`STEP_DT = 1/30`），渲染每帧插值 |
| 地图 | 96×96 格，TILE = 32px，世界 3072×3072px |
| 当前阶段 | 精灵族完整核心循环可玩：单机 vs AI，1V1 |

### 1.1 原作核心规则摘要（复原基准）

- **种族**：精灵（17 卡）、血兽（18 卡）、亡灵（18 卡）；每族含 1本兵×3、2本兵×6~7、3本兵×4、英雄×4、防御塔×1。品质：白(1本)/蓝(2本)/紫(3本、英雄)。
- **出战卡组**：6 张兵团卡 + 3 张英雄卡，对局内只能生产卡组内的单位。
- **经济**：原作为**占领式**（无农民）：基地自动产出 + 占领野外矿产/据点产出 + 击杀野怪掉落资源与随机魔法。
- **地图元素**：金矿（占领产出）、据点（占领后可作前进出兵点）、野怪营地（击杀大型野怪后其尸体单位沿固定路线进攻）。
- **全局操作**：回城 / 侦查 / 集合 / 集火 四个全局按钮 + 英雄主动技能。
- **对局节奏**：单局约 12 分钟，主打 1V1 / 3V3。
- **胜负**：摧毁敌方主基地。

### 1.2 与原作的差异决策表（重要）

| # | 设计点 | 原作 | 本项目现状 | 决策 |
|---|---|---|---|---|
| D1 | 农民采集 | 无农民，占领式经济 | ✅ 有工人采集（经典 RTS 式） | **保留工人采集**作为基础经济（已验证好玩），原版矿产/据点占领作为**额外经济层**叠加（见路线图 P2） |
| D2 | 卡组出战 | 6+3 卡组限制 | ⬜ 全兵种可直接生产 | 复原卡组系统（P1），对局前选卡 |
| D3 | 飞行单位 | 有（烈焰飞龙/飞龙骑士/长舌幽灵等） | ⬜ 无 | 复原（P0），含对空/对地标签 |
| D4 | 魔法掉落 | 击杀野怪掉落随机魔法 | ⬜ 无 | 复原（P2） |
| D5 | 大型野怪推线 | 大野怪死后为我方沿路线进攻 | ⬜ 无 | 复原（P2） |
| D6 | 全局技能 | 回城/侦查/集合/集火 | ⬜ 有框选/编队等鼠标操作 | 复原为快捷键+按钮（P2） |
| D7 | 对局时长 | ~12 分钟 | 不限 | 保留可调（AI 强度随时间曲线已接近） |
| D8 | 兵种/英雄科技 | 兵种与英雄可分别升级科技 | 🚧 仅主基地 1/2/3 本 | 复原兵种科技与英雄技能升级（P1） |
| D9 | 多人对战 | 1V1/3V3 联网 | ⬜ 单机 vs AI | 先 2V2（AI 队友），联网后置（P5/P7） |

## 2. 核心循环

```
采集/产出 ──> 建造建筑 ──> 生产兵种/召唤英雄 ──> MF打野升级/抢矿扩张
   ▲                                                      │
   └────── 资源反哺 <── 赏金/占领产出 <── 战斗(推线/防守) <──┘
                                        │
                              摧毁敌方主基地 → 胜利
```

三本科技树节奏（参考值，已实现）：2本 ≈ 90~120s 到达，3本 ≈ 4~6 分钟，主力决战 ≈ 6~10 分钟。

## 3. 经济与资源

| 资源 | 获取方式 | 用途 | 状态 |
|---|---|---|---|
| 金币 | 工人采矿（10/趟，2s 挖矿）、野怪赏金、（规划：矿产占领） | 造兵/建筑/科技 | ✅ |
| 原石 | 原石神龛 1.2/s、野怪赏金 | 科技、高级兵种、英雄 | ✅ |
| 人口 | 主基地 10 + 树屋 8，上限 60 | 限制爆兵 | ✅ |
| 英雄经验 | 击杀任意敌方/野怪单位 | 英雄升级 | ✅ |

开局：金币 700 / 原石 150 / 5 工人 / 主基地×1（出生兵力：英雄待召唤）。

### 战斗公式（已实现）

- 普通伤害：`eff = max(1, dmg − armor)`（减法护甲）
- 溅射：落点半径内 `max(1, dmg × 0.5 − armor)`
- 攻城（siege）：对建筑 ×2 伤害
- 弹道速度：340 px/s
- 索敌半径：170px；攻击不可及则追击（chase）

### 5.2 建筑规则

- 工人摆放蓝图 → 走到位置 → 建造（多工人可加速，`buildSpeed` 系数）。
- 建筑生产队列最多 5；点击队列可取消退款。
- 建造菜单：`house / barracks / extractor / arcane / tower`（科技门槛校验）。
- 规划（P2）：野外**矿产据点**可建造「分基地主建筑」（成本 ×1.5），解锁前线出兵。

## 6. 英雄系统（✅ 框架已实现）

- 经验阈值：`[0, 150, 400, 800, 1400]`（上限 5 级），击杀共享经验按范围结算。
- 每级全属性 +12%（`HERO_LEVEL_BONUS`）。
- 法力：上限 200，回复 2/s（`HERO_MANA_REGEN`）。
- 技能：Q/W 手动施放（点技能→点目标/自中心），冷却与耗蓝见各英雄表。
- 死亡：进入 20s 复活倒计时（`HERO_RESPAWN`），在主基地重生。
- 规划（P1）：英雄商店（智慧古树）可召唤最多 3 名英雄（对齐卡组 3 英雄位）。
