## 三、P6 表现层升级（本次完成）

### 已实现

- **音效/环境音/BGM**（[audio.ts](../src/audio.ts) 新建）：WebAudio 全合成零外部资源
  - SFX：选择/指令确认/放置建筑/训练排队/建造完成/科技完成/魔法球/波次来袭/胜负 stinger/战斗命中（90ms 节流 + 随机音色）
  - BGM：低音区四和弦 pad 循环（Am→F→G→Em，8.5s 换和弦，双失谐振荡器 + 慢包络）
  - 接线：`game.onSound` 钩子（trainUnit/placeBuilding/onBuildingCompleted/setTech/applyOrb/dealDamage/scenario 波次）；首次交互解锁 AudioContext；顶栏 🔊 按钮 + M 键静音
- **单位动画**：地面单位移动正弦起伏（bob，仅表现层不影响模拟）；与既有攻击白点/受击闪白/飞行悬浮/buff 环/英雄金环叠加
- **触屏适配**（[input.ts](../src/input.ts)）：`pointers` 多点跟踪 + 双指捏合缩放（起始中点世界坐标锚定）+ 双指平移；`touch-action:none` 禁浏览器手势；pointercancel 清理；回放模式同样可用
- **渲染性能**（[renderer.ts](../src/renderer.ts)）：
  - 镜头视口剔除：建筑/单位/弹道/魔法球/尸体屏外跳过（96px 余量）
  - 雾瓦片行程合并：同行连续同状态瓦片合并为单矩形（配合既有 fogVersion 脏检查）

### 验证状态

- `tsc --noEmit` ✅、`npm run build` ✅
- p4/p5/p5-save/p5-scenario/p5-replay 模拟回归 ✅（P4 A-D 场景 45 项 + P5 各 27/10/25/11 项）
- P4 场景 E 无死锁误报修复：实测胜负集中在 300-500s，快模式 400s 上限截断导致平局误判 → 上限调至 560s（700s 对照实验：全部胜负 ≤505s，非死锁）

### 关键设计

1. **音频零耦合**：audio.ts 只被表现层（main/input）引用，模拟层仅经 `onSound` 回调通知，不影响回放确定性
2. **捏合锚定**：pinchStart 记录起始指距/缩放/中点世界坐标，缩放=起始缩放×指距比，起始世界点恒跟随双指中点——缩放平移复合手势无漂移
3. **剔除余量 96px**：覆盖英雄等级角标/血条/buff 环等超出本体的绘制
