## P0 精灵族补全 + 单位特性系统（地基）

### 功能清单

- [x] **特性系统**（`entities.ts` + 新 `src/traits.ts`）：`flying（飞行，仅可被对空攻击）、antiAir（对空倍率）、splash、siegeX2、regen（再生）、aura（光环）、onKill（击杀触发）、deathSplit（死亡分裂）、crit（暴击）、slow（减速弹）、shield（护盾）、summon（召唤临时单位）`
- [x] 飞行寻路：飞行单位走直线（无视地形），渲染加悬浮阴影
- [x] 索敌过滤：近战地面单位不打飞行；对空倍率作用于 `antiAir` 单位
- [x] 精灵补卡（策划文档 §4.1）：大树人（治疗）、丛林小鹿（减速）、烈焰飞龙（飞行）、精灵老师（攻击光环）、月光刺客（闪现斩杀）
- [x] 精灵补英雄 ×3：顽皮公主爱尔（点地炮击）、烈焰绿龙基蒙（飞行喷火）、森林长老福瑞斯（治疗+召唤树人）
- [x] 英雄商店：智慧古树可召唤最多 3 名英雄
- [x] UI 指令卡随兵种特性显示说明

### 涉及文件

`src/traits.ts`(新)、`src/types.ts`（UnitDef 加 traits 字段）、`src/entities.ts`、`src/game.ts`（dealDamage 对空/暴击/反伤结算）、`src/config.ts`、`src/renderer.ts`（飞行阴影）、`src/ai.ts`

### 验收

1. 烈焰飞龙可越过树林直线飞行，地面近战无法选中攻击它，木精灵可打
2. 月光刺客闪现到残血单位背后完成斩杀

## 里程碑依赖关系

```
P0 特性地基 ──> P1 卡组科技 ──> P2 地图机制 ──> P3 血兽 ──> P4 亡灵 ──> P5 模式
      └──────────── P6 表现层（随时并行）           └────────> P7 联网 / P8 Godot
```

**建议顺序**：P0 → P1 → P2 是「玩法完整复原」的最短路径；P3/P4 是「内容完整复原」；P5 之后属于扩展。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 三族平衡工作量爆炸 | 无头模拟批量跑分（P4 的 balance-sim），数值只调 config |
| buff/召唤/尸体系统复杂度 | 全部走 traits 通用实现，禁止卡内写死 |
| 确定性被浮点破坏（回放/联机） | 模拟层禁用 `Math.random`，统一走种子随机（现有野怪重生已隐含此需求） |
| Godot 迁移二次开发 | 保持模拟层纯函数化，输入→状态推进单一入口（game.update 已满足） |
